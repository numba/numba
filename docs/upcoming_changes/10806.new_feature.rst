Support calling closures with ``*args`` and fix closure argument binding
------------------------------------------------------------------------

Calling a closure with an unpacked tuple, e.g. ``closure(*args)``, previously
raised ``UnsupportedError``. When the tuple is built in the enclosing
function, the closure inliner now unpacks it into direct arguments and
inlines the call as usual. Varargs that are not locally built tuples (e.g. a
tuple passed in as a parameter) remain unsupported.

Inlined closure calls now also bind arguments against the closure's
signature. Previously keyword arguments were ignored, every default was
appended even when some had been passed positionally, and surplus positional
arguments were dropped, all silently producing wrong results. Keyword
arguments now bind by name and mismatched calls raise ``TypingError``.
