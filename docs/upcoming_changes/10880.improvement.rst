Accept ``nogil`` option in ``@vectorize`` and ``@guvectorize``
--------------------------------------------------------------

The ``nogil`` keyword is now accepted by ``@vectorize`` and
``@guvectorize``, matching the behavior of ``@njit``. This enables
consistent option passing in frameworks like Dask that apply ``nogil``
uniformly. Since ufuncs and gufuncs always release the GIL via NumPy's
ufunc dispatch machinery regardless of this option, passing ``nogil``
now raises a ``NumbaInvalidConfigWarning`` to make that explicit.
