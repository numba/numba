Fix race condition in GUFunc caching that can cause segfaults
-------------------------------------------------------------

Fixed a race condition where concurrent processes compiling the same
``@guvectorize`` functions could produce inconsistent cache files, leading to
segfaults. The ABI version tag used to disambiguate compiled functions in
``FunctionIdentity`` depended on compilation order, and, for functions with
more than one signature, on which signatures were already cached. Two processes
could therefore bake different ABI tags into the ``.nbc`` kernel cache and the
``guf-*.nbc`` wrapper cache for the same signature; loading the mismatched pair
returned a null function pointer and segfaulted.

The ABI tag is now a deterministic function of the function's identity -- its
bytecode, source contents, definition line and any closure cells -- so every
overload gets the same tag across processes regardless of compilation order or
cache state.
