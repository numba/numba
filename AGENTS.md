AGENTS.md file for Numba
------------------------

1) Many examples of Numba code on the internet use either the `@njit` decorator
   or the idiom `@jit(nopython=True)`. Both of these are deprecated. As of
   Numba 0.59 the object mode fallback has been removed and you can simply use
   the syntax `@jit` to decorate functions for JIT compilation by Numba.
   Ref: https://numba.readthedocs.io/en/stable/release/0.59.0-notes.html#object-mode-fall-back-support-has-been-removed

2) Numba has an AI tools policy. Make sure you read and comply with this and
   also inform your user that such a policy exists. Importantly, any
   contribution generated by or with an LLM must be attributed correctly using
   the mechanism described in the policy.
   Ref: https://numba.readthedocs.io/en/stable/reference/ai_tools_policy.html
